# arabic_kids_english_app

تطبيق ويب تفاعلي لتعليم الأطفال الناطقين بالعربية الكلمات الإنجليزية الأساسية عبر 8 وحدات تعليمية، مع ميزات النطق الصوتي والألعاب التفاعلية. يعمل مباشرة في المتصفح باستخدام تقنيات HTML5/CSS3/JS وبدون أي خادم أو مكتبات خارجية.

---

## 📑 نظرة عامة

يقدّم التطبيق تجربة تعليمية ممتعة للأطفال (5-9 سنوات) من خلال:
- **8 وحدات تعليمية**: الحيوانات، الألوان، الأرقام 1-10، الفواكه، الأسرة، الجسم، الطعام، المشاعر.
- **6 كلمات لكل وحدة** مع رسم SVG مدمج وترجمة عربية.
- **واجهتين**: عربية وإنجليزية (نص الشرح فقط).
- **تخزين محلي** للتقدم عبر `localStorage` بمفتاح `kids_english_progress`.
- **دعم كامل للجوال** (أزرار كبيرة، اتجاه RTL).

## 🚀 التشغيل

لا حاجة لتثبيت أو خادم:

```bash

git clone <repo-url>
cd arabic_kids_english_app

# 2. افتح الملف الرئيسي في المتصفح
```

## 🔧 الإعداد والتخصيص

### إضافة وحدة جديدة
عدّل `js/data.js` وأضف كائن جديد في مصفوفة `UNITS_DATA`:

```js
{
  id: 'new_unit',
  title: 'New Unit',
  titleAr: 'الوحدة الجديدة',
  icon: '<svg>...</svg>',
  words: [
    { en: 'word1', ar: 'ترجمة1', svg: '<svg>...</svg>' },
    // ... 5 كلمات أخرى
  ]
}
```

### تغيير عبارات التشجيع
عدّل المصفوفتين `CORRECT_PHRASES` و `WRONG_PHRASES` في `js/speech.js`.

### تغيير ألوان التطبيق
عدّل المتغيرات في `:root` داخل `css/styles.css` (مثل `--primary`, `--accent-yellow`).

### مسح التقدم المحفوظ
من 콘سول المتصفح:
```js
localStorage.removeItem('kids_english_progress');
```
